# Channel & host research log

Dates in UTC. This file records **what was reviewed, what was approved, and what
was deliberately excluded** when the catalog grew from 248 to 1,059+ reviewed US
channels (2026-09-25 session) and how playback is verified.

## How approval works

A channel only reaches `generated/` when its stream URL is:

1. direct HTTPS HLS (`.m3u8` path, no credentials, no expiring signed query,
   no IP-literal host, port 443 only), **and**
2. matched by a rule in [`config/policy.json`](config/policy.json):
   a reviewed host, a reviewed host suffix (B2B FAST playout platforms), or a
   specific channel-ID + host pair with an evidence URL, **and**
3. not on the pay-TV exclusion list.

Candidate playlists ([`config/sources.json`](config/sources.json)) are only
candidate supplies — inclusion in an upstream playlist is never the approval.

## Playback verification

`scripts/verify_channels.py` (run by the **Verify channel streams** workflow)
probes every catalog URL and the root bulk playlist:

1. fetch the HLS master manifest (following redirects),
2. fetch a media playlist rendition,
3. download one complete media segment and check container bytes
   (MPEG-TS sync / ISO-BMFF `ftyp` / ADTS), not decode it.

Statuses: `segment_ok`, `manifest_ok`, `geo_blocked` (HTTP 451),
`unavailable` (definitive miss: 404/410, DNS failure, non-HLS body),
`inconclusive` (network/TLS/timeout/5xx/401/403 — **not** evidence of death).

Results land in [`generated/verification.json`](generated/verification.json):

- `generated/playlists/usa-verified.m3u` = catalog entries that returned a
  real media segment on the last run;
- root `usa-verified.m3u` = the repository's original bulk playlist (the
  4,021-entry file uploaded to `main`) filtered to entries that are still
  policy-format HTTPS HLS **and** returned a media segment; per-entry
  `policy_format` flags show which survivors would also pass host review.

Caveats that a probe cannot remove: one runner location (GitHub-hosted, US),
one moment, regional blackouts, short-lived ad/SSAI failures, and terms of
service. `segment_ok` means "a playable segment loaded here, now" — nothing
about rights or your location.
